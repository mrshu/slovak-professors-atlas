# Atlas research

This directory holds reproducible investigations that extend the Slovak Professors Atlas without weakening its source contract.

Research claims use three labels:

- **Measured** — computed from pinned source files or `public/data/atlas.json`.
- **Documented** — stated by a cited primary or official external source.
- **Hypothesis** — an interpretation that still needs a null model, sensitivity analysis, or better linkage.

Every publishable result must identify its unit of observation, time coverage, denominator, missing-data policy, and at least one inversion or disconfirmation check. Appointment events are not unique people, professor stock changes, vacancies, academic quality, or causal effects.

## Workflow

1. Start with [`evidence-map.md`](evidence-map.md).
2. Record broad candidates before selecting deep dives.
3. Add deterministic analysis code and machine-readable outputs together.
4. Test robustness before interpreting a correlation.
5. Keep external source metadata and licenses beside each correlation input.
